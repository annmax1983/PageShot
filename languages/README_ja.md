# PageShot

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

フルページ・表示領域・選択範囲のスクリーンショットを撮影できる軽量ブラウザ拡張機能です。ウォーターマークの強制付与はなく、処理はすべてローカルで完結します。

> Chromium系ブラウザ対応 · Manifest V3 · トラッキングなし · すべてブラウザ内で処理

---

## PageShotの特長

ほとんどのスクリーンショットツールは、フルページキャプチャに課金したり、ウォーターマークを付けたり、データをリモートサーバーにアップロードします。PageShotはブラウザ内ですべて完結するため、データがマシンの外に出ることはありません。

| 特長 | 詳細 |
|-----------|--------|
| 🔒 **プライバシー最優先** | すべての処理はローカルで実行されます。サーバーへのアップロードもトラッキングもありません。 |
| 💧 **ウォーターマークなし** | クリーンなスクリーンショット。キャプチャにブランドが強制されることはありません。 |
| 🆓 **画像へのウォーターマーク強制なし** |
| 📄 **フルページキャプチャ** | ワンクリックで長文スクロールキャプチャ — 自動的にスクロールして結合します。 |
| 📋 **コピー＆ペースト** | キャプチャ後すぐにクリップボードにコピー — チャット・メール・ドキュメントに直接貼り付けできます。 |
| ✏️ **アノテーション機能** | 共有前に矩形描画やモザイクぼかしが可能です。 |
| ⚡ **軽量** | フレームワーク不使用、無駄なコードなし。 |
| 🌍 **6言語対応** | ブラウザの言語設定を自動検出します。 |

## インストール

### ソースから（開発者モード）

1. ブラウザの拡張機能ページを開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. **デベロッパーモード**を有効にします（右上のトグル）
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`page-shot`フォルダを選択します
4. ツールバーにPageShotアイコンが表示されます

## 使い方

### 右クリックキャプチャ

1. Webページ上の任意の場所を右クリックします
2. コンテキストメニューから**PageShot**を選択します
3. **表示領域をキャプチャ**、**フルページをキャプチャ**、または**選択範囲をキャプチャ**を選択します
4. トースト通知に**コピー**、**ダウンロード**、**編集**ボタンが表示されます

### キーボードショートカット

| ショートカット | アクション |
|----------|--------|
| `Ctrl+Shift+V` | 表示領域キャプチャ → クリップボードにコピー |
| `Ctrl+Shift+F` | フルページキャプチャ → PNGとしてダウンロード |
| `Ctrl+Shift+S` | 選択モードに入る |

### アノテーション

1. キャプチャ後、トーストの**✏️ 編集**をクリックします
2. 新しいタブでアノテーションエディタが開きます
3. ツールバーから**矩形**または**モザイク**ツールを使用します
4. （矩形の場合）色を選択します
5. 完了したら**📋 コピー**または**💾 ダウンロード**をクリックします

## プライバシー

PageShotはプライバシーを核となる原則として構築されています：

- ✅ **データアップロードなし** — スクリーンショット処理はすべてローカルで実行されます
- ✅ **アナリティクスなし** — トラッキング、テレメトリ、リモート呼び出しなし
- ✅ **Cookie不使用** — ブラウザCookieの読み書きは行いません
- ✅ **閲覧履歴不参照** — ブラウザデータへのアクセスは行いません
- ✅ **一時保存のみ** — スクリーンショットは処理中に一時的に存在し、処理後にクリアされます
- ✅ **最小限の権限** — 必要最小限の権限のみを要求します

## 動作の仕組み

```
トリガー（右クリック / ショートカット / ポップアップ）
       ↓
Service Workerがキャプチャを調整
       ↓
┌─ 表示領域: chrome.tabs.captureVisibleTab()
├─ フルページ: CDPでビューポートを拡張 → 高解像度キャプチャを一括取得
└─ 選択範囲: 表示領域をキャプチャ → 選択矩形にクロップ
       ↓
Offscreen Documentで画像を処理（クロップ / クリップボード）
       ↓
トースト通知にコピー / ダウンロード / 編集アクションを表示
```

> **Offscreenが必要な理由** ChromeのManifest V3ではService Workerとしてバックグラウンドが実行され、DOMアクセスがありません。Canvas APIにはDOMが必要なため、ChromeのOffscreen APIを使用して画像処理を行っています。

## 権限

| 権限 | 用途 |
|-----------|---------|
| `activeTab` | キャプチャ実行時に現在のタブにアクセス |
| `contextMenus` | 右クリックメニューにオプションを追加 |
| `downloads` | スクリーンショットをコンピュータに保存 |
| `clipboardWrite` | スクリーンショットをクリップボードにコピー |
| `scripting` | Webページに選択オーバーレイを注入 |
| `storage` | 設定をローカルに保存 |
| `offscreen` | バックグラウンドで画像を処理 |
| `tabs` | キャプチャ調整用のタブ情報を取得 |
| `debugger` | 特定のChromiumビルドでフルページスクリーンショットの結合に必要 |
