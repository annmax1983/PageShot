軽量なブラウザ拡張機能 — フルページ、表示領域、選択範囲のスクリーンショット。強制透かしなし、完全ローカル処理。

> Chromium ベース · Manifest V3 · トラッキングなし · 完全ブラウザ内処理

---

## なぜ PageShot？

ほとんどのスクリーンショットツールはフルページキャプチャに課金したり、透かしを入れたり、データをリモートサーバーにアップロードします。PageShot はすべてブラウザ内で完結 — データがデバイスから離れることはありません。

| 利点 | 詳細 |
|------|------|
| 🔒 **完全プライベート** | すべてローカル処理。サーバーなし、アップロードなし、トラッキングなし。 |
| 💧 **透かしなし** | クリーンなスクリーンショット。ブランドロゴなし。 |
| 🆓 **透かしなし** | キャプチャに強制透かしを付けません。 |
| 📄 **フルページ** | ワンクリック長截图 — 自動スクロール＆結合。 |
| 📋 **コピー＆ペースト** | キャプチャ後にクリップボードへ即コピー — チャットやメールに直接貼り付け。 |
| ✏️ **アノテーション搭載** | 共有前に矩形描画とモザイクぼかしが可能。 |
| ⚡ **軽量** | 100KB未満。フレームワークなし。 |
| 🌍 **6言語対応** | ブラウザ言語を自動検出。 |

## 機能一覧

| 機能 | 説明 |
|------|------|
| 📄 **フルページキャプチャ** | スクロール可能なページ全体をキャプチャ。遅延読み込み画像対応、超長ページ（10,000px+）も安定。 |
| 👁 **表示領域キャプチャ** | 現在画面に表示されている内容を即座にキャプチャ。 |
| ✂️ **範囲選択キャプチャ** | ドラッグで任意の領域を選択。十字カーカーで精密操作。 |
| 📋 **クリップボードにコピー** | キャプチャ後にワンクリックコピー。Ctrl+V でどこにでも貼り付け。 |
| 💾 **PNG でダウンロード** | 自動命名：ページタイトル + 日付。 |
| ✏️ **矩形アノテーション** | カラー矩形で重要エリアをマーク。5色利用可能。 |
| 🟦 **モザイクぼかし** | 機密コンテンツをピクセル化 — パスワード、個人情報。 |
| ⌨️ **キーボードショートカット** | `Ctrl+Shift+V` 表示＋コピー · `Ctrl+Shift+F` フルページ＋ダウンロード · `Ctrl+Shift+S` 選択モード。 |
| 🔤 **6言語i18n** | UIがブラウザ言語に自動対応：English、中文、日本語、Español、Deutsch、Français。 |
| 🔒 **固定要素処理** | 長いスクリーンショットの固定ヘッダー/フッターを自動検出・除去。 |

## インストール

1. 拡張機能ページを開く：**Chrome** → `chrome://extensions/` / **Edge** → `edge://extensions/`
2. **デベロッパーモード**を有効化
3. **パッケージ化されていない拡張機能を読み込む**をクリックし `page-shot` フォルダを選択
4. ツールバーに PageShot アイコンが表示されます

## 使い方

### 右クリックキャプチャ

1. Webページ上で右クリック
2. **PageShot** を選択
3. **表示領域**、**フルページ**、**範囲選択** を選択
4. **コピー**、**ダウンロード**、**編集** のトーストが表示

### キーボードショートカット

| ショートカット | アクション |
|---------------|-----------|
| `Ctrl+Shift+V` | 表示領域をキャプチャ → コピー |
| `Ctrl+Shift+F` | フルページ → ダウンロード |
| `Ctrl+Shift+S` | 選択モード |
