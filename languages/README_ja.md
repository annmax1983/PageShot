# PageShot

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

フルページ・表示領域・選択範囲のスクリーンショットを撮影できる軽量ブラウザ拡張機能です。ウォーターマークの強制付与はなく、処理はすべてローカルで完結します。

> Chrome / Edge / Firefox · Manifest V3 · トラッキングなし · すべてブラウザ内で処理

---

## PageShotの特長

ほとんどのスクリーンショットツールは、フルページキャプチャに課金したり、ウォーターマークを付けたり、データをリモートサーバーにアップロードします。PageShotはブラウザ内ですべて完結するため、スクリーンショットのデータがマシンの外に出ることはありません。

| 特長 | 詳細 |
|-----------|--------|
| 🔒 **プライバシー最優先** | すべての処理はローカルで実行されます。アップロードもトラッキングもありません。外部への通信は任意のライセンス検証のみです。 |
| 💧 **ウォーターマークなし** | クリーンなスクリーンショット。キャプチャにブランドが強制されることはありません。 |
| 📄 **フルページキャプチャ** | ワンクリックで長文スクロールキャプチャ — 自動的にスクロールして結合します。 |
| 📋 **コピー＆ペースト** | キャプチャ後すぐにクリップボードにコピー — チャット・メール・ドキュメントに直接貼り付けできます。 |
| ✏️ **アノテーション機能** | 共有前に矩形・楕円・矢印・テキストの描画やモザイクぼかしが可能です。 |
| ⚡ **軽量** | フレームワーク不使用、無駄なコードなし。 |
| 🌍 **6言語対応** | ブラウザの言語設定を自動検出します。 |

## 使い方

### 右クリックキャプチャ

1. Webページ上の任意の場所を右クリックします
2. コンテキストメニューから**PageShot**を選択します
3. **表示領域をキャプチャ**、**フルページをキャプチャ**、または**選択範囲をキャプチャ**を選択します
4. トースト通知に**コピー**、**ダウンロード**、**編集**ボタンが表示されます

### キーボードショートカット

| ショートカット | アクション |
|----------|--------|
| `Ctrl+Shift+V` | 表示領域キャプチャ → クリップボードにコピー |
| `Ctrl+Shift+F` | フルページキャプチャ → PNGとしてダウンロード |
| `Ctrl+Shift+S` | 選択モードに入る |

### アノテーション

1. キャプチャ後、トーストの**✏️ 編集**をクリックします
2. 新しいタブでアノテーションエディタが開きます
3. ツールバーから**矩形**・**楕円**・**矢印**・**テキスト**・**モザイク**ツールを使用します
4. （図形とテキストの場合）色を選択します
5. 完了したら**📋 コピー**または**💾 ダウンロード**をクリックします

## プライバシー

PageShotはプライバシーを核となる原則として構築されています：

- ✅ **データアップロードなし** — スクリーンショット処理はすべてローカルで実行されます
- ✅ **アナリティクスなし** — トラッキング、テレメトリ、リモート呼び出しは任意のライセンス検証のみ
- ✅ **Cookie不使用** — ブラウザCookieの読み書きは行いません
- ✅ **閲覧履歴不参照** — ブラウザデータへのアクセスは行いません
- ✅ **ローカル編集用ストレージ** — 直近5件のキャプチャは注釈エディター用にブラウザ内へ保存され、それより古いものは自動的に削除されます。アップロードは一切ありません
- ✅ **最小限の権限** — 必要最小限の権限のみを要求します

---

## 動作の仕組み

1. 右クリックメニュー、キーボードショートカット、またはポップアップからキャプチャを開始します。
2. 撮影範囲を選びます：表示領域、ページ全体、または自分で選択した領域。
3. 画像はブラウザ内だけでトリミング・処理されます。
4. 通知に **コピー**、**ダウンロード**、**編集** の選択肢が表示されます。

## 権限

| 権限 | 用途 |
|-----------|---------|
| `activeTab` | キャプチャ実行時に現在のタブにアクセス |
| `contextMenus` | 右クリックメニューにオプションを追加 |
| `downloads` | スクリーンショットをコンピュータに保存 |
| `clipboardWrite` | スクリーンショットをクリップボードにコピー |
| `scripting` | Webページに選択オーバーレイを注入 |
| `storage` | 設定をローカルに保存 |
| `offscreen` | バックグラウンドで画像を処理 |
| `tabs` | キャプチャ調整用のタブ情報を取得 |
| `debugger` | 特定のChromiumビルドでフルページスクリーンショットの結合に必要 （Chrome / Edge のみ） |
