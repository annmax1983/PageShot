# PageShot
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

轻量级浏览器截图插件 — 全页长截图、可见区域截图、选区截图。无强制水印，本地处理处理。

> 基于 Chromium · Manifest V3 · 无追踪 · 全部在浏览器内完成

---

## 为什么选择 PageShot？

大多数截图工具要么收费、要么加水印、要么把你的数据上传到服务器。PageShot 一切在浏览器本地完成 — 你的数据永远不会离开你的电脑。

| 优势 | 详情 |
|------|------|
| 🔒 **隐私优先** | 所有处理在本地完成。无服务器、无上传、无追踪。 |
| 💧 **无水印** | 干净的截图，不会强加任何品牌标识。 |
| 🆓 **截图无强制水印。 |
| 📄 **全页长截图** | 一键截取整个页面 — 自动滚动、自动拼接。 |
| 📋 **一键复制** | 截图后直接复制到剪贴板 — 粘贴到微信、钉钉、邮件。 |
| ✏️ **内置标注** | 分享前可以画矩形框、打马赛克。 |
| ⚡ **极简轻量** | 不到 100KB，无框架依赖。 |
| 🌍 **6 种语言** | 自动识别浏览器语言。 |

## 功能特性

| 功能 | 说明 |
|------|------|
| 📄 **全页长截图** | 自动滚动页面，逐段截图并拼接为完整长图。支持懒加载图片，超长页面（10000px+）不崩溃。 |
| 👁 **可见区域截图** | 截取当前屏幕显示的内容，最快的截图方式。 |
| ✂️ **选区截图** | 拖拽选择任意区域，十字光标精准定位。 |
| 📋 **复制到剪贴板** | 截图后一键复制，直接 Ctrl+V 粘贴到任何应用。 |
| 💾 **下载保存 PNG** | 自动命名：页面标题 + 日期（如 `GitHub_-_首页_2026-07-07.png`）。 |
| ✏️ **矩形标注** | 用彩色矩形框标记重点区域。5 种颜色：红、蓝、绿、黑、白。 |
| 🟦 **马赛克模糊** | 像素化敏感内容 — 密码、个人信息、私密消息。 |
| ⌨️ **快捷键** | `Ctrl+Shift+V` 截取可见区域并复制 · `Ctrl+Shift+F` 截取全页并下载 · `Ctrl+Shift+S` 选区模式。 |
| 🔤 **6 语言界面** | 自动匹配浏览器语言：English、中文、日本語、Español、Deutsch、Français。 |
| 🔒 **固定元素处理** | 自动识别并去除长截图中的固定顶栏/底栏，避免重复。 |

## 安装方式

### 开发者模式加载

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择 `page-shot` 文件夹
4. 工具栏出现 PageShot 图标

---

## 使用方法

### 右键截图

1. 在网页上任意位置右键
2. 选择 **PageShot**
3. 选择：**截取可见区域**、**截取全页长图** 或 **选定区域截图**
4. 弹出操作栏：**复制**、**下载**、**标注**

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+V` | 截取可见区域 → 复制到剪贴板 |
| `Ctrl+Shift+F` | 截取全页 → 下载为 PNG |
| `Ctrl+Shift+S` | 进入选区模式 |

### 标注

1. 截图后点击操作栏上的 **✏️ 标注**
2. 标注编辑器在新标签页打开
3. 使用工具栏的 **矩形** 或 **马赛克** 工具
4. 选择颜色（矩形工具）
5. 完成后点击 **📋 复制** 或 **💾 下载**

## 隐私保护

PageShot 以隐私为核心设计原则：

- ✅ **无数据上传** — 所有截图处理在本地完成
- ✅ **无分析追踪** — 无遥测、无远程调用
- ✅ **无 Cookie** — 不读取或写入浏览器 Cookie
- ✅ **无浏览历史** — 不访问你的浏览数据
- ✅ **临时存储** — 截图仅在处理期间短暂存在，之后清除
- ✅ **最小权限** — 只申请必要的权限

## 工作原理

```
触发（右键 / 快捷键 / 弹窗）
       ↓
Service Worker 协调截图流程
       ↓
┌─ 可见区域：chrome.tabs.captureVisibleTab()
├─ 全页长图：滚动 → 逐段截图 → Canvas 拼接
└─ 选区截图：截取可见区域 → 裁剪到选区范围
       ↓
Offscreen Document 处理图片（拼接 / 裁剪 / 剪贴板）
       ↓
弹出 Toast 通知，提供 复制 / 下载 / 标注 操作
```

> **为什么需要 Offscreen？** Chrome 的 Manifest V3 将后台运行在 Service Worker 中，没有 DOM 访问权限。Canvas API 需要 DOM，所以使用 Chrome 的 Offscreen API 创建隐藏文档来处理图片。

## 权限说明

| 权限 | 用途 |
|------|------|
| `activeTab` | 触发截图时访问当前标签页 |
| `contextMenus` | 添加右键菜单选项 |
| `downloads` | 保存截图到本地 |
| `clipboardWrite` | 复制截图到剪贴板 |
| `scripting` | 注入选区覆盖层 |
| `storage` | 本地保存设置 |
| `offscreen` | 后台处理图片 |
| `tabs` | 获取标签页信息用于截图协调 |
