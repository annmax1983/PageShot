轻量级浏览器截图插件 — 全页长截图、可见区域截图、选区截图。无强制水印，本地处理处理。

> 基于 Chromium · Manifest V3 · 无追踪 · 全部在浏览器内完成

---

## 为什么选择 PageShot？

大多数截图工具要么收费、要么加水印、要么把你的数据上传到服务器。PageShot 一切在浏览器本地完成 — 你的截图数据永远不会离开你的电脑。

| 优势 | 详情 |
|------|------|
| 🔒 **隐私优先** | 所有处理在本地完成。无上传、无追踪。唯一的对外请求是可选的授权验证。 |
| 💧 **无水印** | 干净的截图，不会强加任何品牌标识。 |
| 📄 **全页长截图** | 一键截取整个页面 — 自动滚动、自动拼接。 |
| 📋 **一键复制** | 截图后直接复制到剪贴板 — 粘贴到微信、钉钉、邮件。 |
| ✏️ **内置标注** | 分享前可以画矩形框、打马赛克。 |
| ⚡ **极简轻量** | 无框架依赖，轻量精简。 |
| 🌍 **6 种语言** | 自动识别浏览器语言。 |

## 使用方法

### 右键截图

1. 在网页上任意位置右键
2. 选择 **PageShot**
3. 选择：**截取可见区域**、**截取全页长图** 或 **选定区域截图**
4. 弹出操作栏：**复制**、**下载**、**标注**

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+V` | 截取可见区域 → 复制到剪贴板 |
| `Ctrl+Shift+F` | 截取全页 → 下载为 PNG |
| `Ctrl+Shift+S` | 进入选区模式 |

### 标注

1. 截图后点击操作栏上的 **✏️ 标注**
2. 标注编辑器在新标签页打开
3. 使用工具栏的 **矩形** 或 **马赛克** 工具
4. 选择颜色（矩形工具）
5. 完成后点击 **📋 复制** 或 **💾 下载**

## 隐私保护

PageShot 以隐私为核心设计原则：

- ✅ **无数据上传** — 所有截图处理在本地完成
- ✅ **无分析追踪** — 无遥测、除可选授权验证外无远程调用
- ✅ **无 Cookie** — 不读取或写入浏览器 Cookie
- ✅ **无浏览历史** — 不访问你的浏览数据
- ✅ **本地编辑存储** — 最近 5 张截图会保留在浏览器中供标注编辑器使用，更早的会自动清理；不会上传任何截图
- ✅ **最小权限** — 只申请必要的权限

## 工作原理

1. 通过右键菜单、快捷键或弹窗发起截图。
2. 选择范围：可见区域、整页长图，或你框选的区域。
3. 裁剪与处理全部在你的浏览器内完成。
4. 随后弹出通知，可直接选择复制、下载或编辑。
