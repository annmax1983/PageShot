# PageShot
[English](../README.md) | [中文](README_zh.md) | Español | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

Extensión ligera de capturas de pantalla — página completa, área visible o selección. Sin marca de agua, procesamiento completamente local.

> Basado en Chromium · Manifest V3 · Sin rastreo · Todo en el navegador

---

## ¿Por qué PageShot?

La mayoría de herramientas de captura cobran por página completa, añaden marcas de agua o suben tus datos a servidores remotos. PageShot hace todo dentro de tu navegador — tus datos nunca salen de tu equipo.

| Ventaja | Detalle |
|---------|---------|
| 🔒 **Completamente privado** | Todo el procesamiento es local. Sin servidores, sin subidas, sin rastreo. |
| 💧 **Sin Marca de Agua** | Capturas limpias, sin branding impuesto. |
| 🆓 **Sin marca de agua** | No se imponen marcas de agua en las capturas. |
| 📄 **Página Completa** | Captura larga con un clic — desplazamiento y ensamblaje automático. |
| 📋 **Copiar y Pegar** | Copia al portapapeles al instante — pega directamente en chats, emails, documentos. |
| ✏️ **Anotación Integrada** | Dibuja rectángulos y desenfoque mosaico antes de compartir. |
| ⚡ **Ligero** | Sin frameworks, sin peso extra. |
| 🌍 **6 Idiomas** | Detección automática del idioma del navegador. |

## Funciones

### 🆓 Funciones Gratuitas

| Función | Descripción |
|---------|-------------|
| 📄 **Captura de Página Completa** | Captura toda la página desplazable. Soporta imágenes lazy-loaded y páginas muy largas (10,000px+). |
| 👁 **Captura de Área Visible** | Captura instantánea de lo que ves en pantalla. |
| ✂️ **Captura por Selección** | Arrastra para seleccionar cualquier región con cursor de precisión. |
| 📋 **Copiar al Portapapeles** | Un clic para copiar después de capturar. Pega con Ctrl+V en cualquier app. |
| 💾 **Descargar como PNG** | Nombra automáticamente: título de página + fecha. |
| ✏️ **Anotación con Rectángulo** | Dibuja rectángulos de colores para resaltar áreas. 5 colores disponibles. |
| 🟦 **Desenfoque Mosaico** | Pixela contenido sensible — contraseñas, información personal. |
| ⌨️ **Atajos de Teclado** | `Ctrl+Shift+V` Visible + copiar · `Ctrl+Shift+F` Página completa + descargar · `Ctrl+Shift+S` Modo selección. |
| 🔤 **i18n en 6 Idiomas** | Interfaz auto-detecta tu idioma: English, 中文, 日本語, Español, Deutsch, Français. |
| 🔒 **Elementos Fijos** | Detecta y elimina headers/footers fijos de capturas largas. |

## Instalación

1. Abre la página de extensiones: **Chrome** → `chrome://extensions/` / **Edge** → `edge://extensions/`
2. Activa el **Modo de desarrollador**
3. Haz clic en **Cargar descomprimida** y selecciona la carpeta `page-shot`
4. El icono de PageShot aparecerá en tu barra de herramientas

---

## Uso

### Captura con Clic Derecho

1. Clic derecho en cualquier página
2. Selecciona **PageShot**
3. Elige: **Área Visible**, **Página Completa** o **Selección**
4. Aparece un toast con **Copiar**, **Descargar** y **Editar**

### Atajos de Teclado

| Atajo | Acción |
|-------|--------|
| `Ctrl+Shift+V` | Capturar visible → copiar |
| `Ctrl+Shift+F` | Capturar página → descargar |
| `Ctrl+Shift+S` | Modo selección |
