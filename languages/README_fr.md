# PageShot
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | Français

Extension légère de capture d'écran — page entière, zone visible ou sélection. Sans filigrane, traitement entièrement local.

> Basé sur Chromium · Manifest V3 · Aucun suivi · Entièrement dans le navigateur

---

## Pourquoi PageShot ?

La plupart des outils de capture facturent la page complète, ajoutent des filigranes ou téléchargent vos données sur des serveurs distants. PageShot fait tout dans votre navigateur — vos données ne quittent jamais votre ordinateur.

| Avantage | Détail |
|----------|--------|
| 🔒 **Entièrement privé** | Tout le traitement est local. Pas de serveurs, pas de téléchargements, pas de suivi. |
| 💧 **Sans Filigrane** | Captures propres, aucun branding imposé. |
| 🆓 **Sans filigrane** | Aucun filigrane forcé sur les captures. |
| 📄 **Page Entière** | Capture longue en un clic — défilement et assemblage automatiques. |
| 📋 **Copier et Coller** | Copie instantanée dans le presse-papiers — collez directement dans les chats, emails, documents. |
| ✏️ **Annotation Intégrée** | Dessinez des rectangles et flou mosaïque avant de partager. |
| ⚡ **Léger** | Pas de frameworks, pas de surcharge. |
| 🌍 **6 Langues** | Détecte automatiquement la langue de votre navigateur. |

## Fonctionnalités

| Fonctionnalité | Description |
|----------------|-------------|
| 📄 **Capture Page Entière** | Capture toute la page défilable. Gère les images en chargement différé et les très longues pages (10 000px+). |
| 👁 **Capture Zone Visible** | Capture instantanée de ce qui est affiché à l'écran. |
| ✂️ **Capture par Sélection** | Glissez pour sélectionner n'importe quelle région avec un curseur de précision. |
| 📋 **Copier dans le Presse-papiers** | Un clic pour copier après la capture. Collez avec Ctrl+V. |
| 💾 **Télécharger en PNG** | Nom automatique : titre de la page + date. |
| ✏️ **Annotation Rectangle** | Dessinez des rectangles colorés pour surligner. 5 couleurs disponibles. |
| 🟦 **Flou Mosaïque** | Pixellise le contenu sensible — mots de passe, informations personnelles. |
| ⌨️ **Raccourcis Clavier** | `Ctrl+Shift+V` Visible + copier · `Ctrl+Shift+F` Page entière + télécharger · `Ctrl+Shift+S` Mode sélection. |
| 🔤 **i18n 6 Langues** | L'interface s'adapte automatiquement à votre langue : English, 中文, 日本語, Español, Deutsch, Français. |
| 🔒 **Éléments Fixes** | Détecte et supprime les headers/footers fixes des longues captures. |

## Installation

1. Ouvrez la page des extensions : **Chrome** → `chrome://extensions/` / **Edge** → `edge://extensions/`
2. Activez le **Mode développeur**
3. Cliquez sur **Charger l'extension non empaquetée** et sélectionnez le dossier `page-shot`
4. L'icône PageShot apparaît dans votre barre d'outils

---

## Utilisation

### Capture par Clic Droit

1. Clic droit sur une page web
2. Sélectionnez **PageShot**
3. Choisissez : **Zone Visible**, **Page Entière** ou **Sélection**
4. Un toast apparaît avec **Copier**, **Télécharger** et **Modifier**

### Raccourcis Clavier

| Raccourci | Action |
|-----------|--------|
| `Ctrl+Shift+V` | Capturer visible → copier |
| `Ctrl+Shift+F` | Capturer page → télécharger |
| `Ctrl+Shift+S` | Mode sélection |
